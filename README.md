# Generate docs with TypeDoc

[TypeDoc](https://typedoc.org/) is used to generate the documentation for a TypeScript project documented with [TSDoc](https://tsdoc.org/). To generate the docs, run the following command:

```bash
npx typedoc --out docs characters --entryPointStrategy expand
```
